# Celebration audio assets

This folder is reserved for pre-generated Vietnamese celebration voice clips used by the game.

Expected files:

- `quynh-xiu.mp3` — energetic Vietnamese child-style cheer: “Xiuuuuuuuuuuuuu!... Con thắng rồi!”
- `ba-yeah.mp3` — energetic Vietnamese adult male cheer: “Yeahhhhhhhhhhhhh!... Ba thắng rồi!”

The game audio engine will play these fixed clips first, then announce the dynamic star total separately in Vietnamese.
